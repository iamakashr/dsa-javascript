## 🛠️ How to Run Locally

### Prerequisites
Install [Node.js](https://nodejs.org) to run JavaScript code outside the browser.

### Execution
Open your terminal inside the project directory and run any file directly:
```bash
node "4. Arrays - Easy-Medium/two-sum.js"
```
*(Note: Because your folder names contain spaces, remember to wrap the file path in quotation marks inside the terminal!)*
